# Hogwarts Themed Web Pages

A visually engaging collection of Hogwarts-inspired web pages featuring magical houses, spells, creatures, and more. Each page is carefully styled to create an immersive experience filled with thematic imagery and layouts that bring the magic of Hogwarts to life.

## About

This repository features a collection of visually appealing Hogwarts-themed web pages. Created with HTML, CSS, and JavaScript, the pages highlight magical houses, spells, creatures, and campus life to offer an engaging and thematic experience.

## Features

- Multiple themed pages focused on different magical Hogwarts elements
- Clean, thematic design with styled content cards and layouts
- Immersive visuals that evoke the Hogwarts atmosphere
- Includes spells, potions, magical creatures, advanced arts, and house information

## File Structure

- HTML files representing different pages such as Houses, Spells & Potions, Magical Creatures & Charms, Advanced Defense & Mystical Arts, and more.
- An Images folder containing the project logo.
- CSS and JavaScript included inline or through linked files for styling and interactivity.


## Usage

Clone or download the repository and open any of the `.html` files in your browser to explore the themed pages.
